A map of the partitions on external drives, and a planner for changing them.

diskmap has no code of its own that writes to a disk. Every change is a command of the tools that come with macOS — diskutil above all — or of the formatter a file system needs; each one is shown before it runs and can be run by hand. Internal and startup disks are only shown.

diskmap is free and comes with no warranty. Changing a partition map can destroy data: keep a copy of anything on the drive you cannot lose. diskmap saves the partition map before each change — not the files on it.
